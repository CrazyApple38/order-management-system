案B

既存ナビバーのタブ並びと一致 / 学習コスト低

  • ✓ 画面切替とベルの位置感が揃い、ナビ全体の一貫性が高い

案C

即応性順

即対応が必要な順 / 集計系（WS）は後ろ
業務管理
  • 順: OB → SL → LA → WS │ 休暇 → 車両 → マスタ
  • ✓ 即応必要な4ベル（OB/SL/LA）が左寄せで視線移動が短い
  • ✓ WS（集計確認系）が後ろにあるため、緊急度の濃淡が出る
  • ✗ ナビバー順とも業務頻度順とも整合しない（独自軸）
案D

横断系優先

承認待ち等の緊急対応系を左に / 管理者向け
業務管理
  • 順: 休暇 → 車両 → マスタ │ OB → SL → WS → LA
  • ✓ 承認待ち件数が左端で最も目立つ（管理者の優先タスク）
  • ✓ ナビバー左端のロゴ近く＝重要度高、と直感的
  • ✗ 一般オペレータの主作業（OB/SL）が右に追いやられる
