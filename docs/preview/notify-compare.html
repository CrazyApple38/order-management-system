統合案 (After) は次フェーズで構築

Before セクションでの視覚すり合わせ後、co-notify-panel.css を作成し、 各画面の現状CSSを置き換えた状態をここに展開します。

  1. LA通知パネルベース + 「最新 / 履歴」タブ追加
  2. 履歴タブに type複数選択 OR フィルタ + 操作者/対象者切替検索
  3. 差分はアコーディオン展開（クリックで開閉）
  4. 各画面に独自タグフィルタ（業務種別など、画面固有）
  5. 未読ドット + 「すべて既読」全画面共通
  6. 行クリックで該当セルへスクロール + ハイライト全画面共通
