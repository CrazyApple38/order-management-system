③ 上書き 個別カスタマイズ (override) — 必要な type だけ手動指定

プリミティブ合成の結果が気に入らない場合、特定セルだけ単一アイコンで上書きできる。マトリクスのセルクリックで「個別上書きモード」に切替→既存の [アイコン選定] モードと同じ IconPicker が起動。

例: type-sl-employee-place をマトリクスから上書き
→ scope=社員 + op=配置 の合成（人物+共有）ではなく、「社員配置」専用の単一アイコン（例: person/si-13878-13878.png 配置済み人物図）を指定
→ このセルだけ マークが付き、override 設定済みであることを表示

④ 解決ロジック アイコン解決順序

co-notify-panel.js 内のアイコン解決ロジック。3 層で順次フォールバック。

type cell-place → ① typeOverrides[cell-place] あり？ → ② primitives[scope=cell] + primitives[op=place] を合成 → ③ 既定アイコン
既存 27 スロット (notifyIconSelections.v1) との関係:
・ ベル7個 + 共通4個 はマトリクス対象外（既存のまま）
・ パネル別 16 個 (type-ob-add/modify/delete 等) は typeOverrides として吸収（互換性維持）
・ 新規追加分はマトリクス合成 (primitive) で表現
