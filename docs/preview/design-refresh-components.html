A. ボタン・入力系 12件

A-01 ボタン階層 新規提案

主操作=青塗り（1画面1〜2個）/ 標準=白ベベル浮き / フラット=ツールバー用（高さ0）/ ゴースト=文字のみ / 危険=薄背景+オレンジ文字（強い塗りにしない: DSルール6.4）。下段はサイズ3種と無効状態。

サイズと無効状態

A-02 アイコンボタン 確立済み

SLモックの右パネル切替（panel-rail）レシピ。白ベベル+elevation-1、active は青リング。アイコンだけの操作には必ず tooltip / aria-label を付ける（design-refresh-plan §4.6）。

小サイズ（26px・行内操作用）

A-03 分割ボタン 新規提案

主動作+選択肢の複合ボタン。「保存して次へ / 保存のみ / 下書き保存」のような既定動作+派生動作に使う。青塗り版と白ベベル版。

A-04 ボタングループ（結合型） 新規提案

角を共有する結合ボタン列。選択状態は log-tab の押し込み表現（インセット影）。丸型 seg（C-01）と役割が重なるため、採用するなら「表示切替=グループ / フィルタ=seg」のような使い分けを決めたい。

A-05 テキスト入力 新規提案

入力欄=押し込み面（インセット例外: 左上暗→右下明）。フォーカスは青リング（panel-rail active と同じ 2px リング）、エラーはオレンジ枠+ヘルプ文字。クリックしてフォーカス状態を確認できます。

A-06 セレクト 新規提案

入力欄と同じ押し込み面+CSS山括弧。ネイティブ select のスタイル統一版（候補一覧のリッチ化はドロップダウンメニュー C-07 を使う）。

A-07 テキストエリア 新規提案

備考・作業内容など複数行入力用。テキスト入力と同じインセット面。

A-08 チェックボックス 新規提案

未選択=インセットの受け皿、選択=青塗り+白チェック（CSS描画）。クリックで切替できます。

A-09 ラジオボタン 新規提案

チェックボックスと同じ語彙の円形版。選択=青塗り+白ドット。排他選択が3〜5個ならseg（C-01）でも代替可。

A-10 トグルスイッチ 新規提案

seg と同じ「凹トラック+浮き白ノブ」語彙。ON=青塗りトラック。設定画面の即時反映スイッチ向け（フォーム送信前提の項目はチェックボックス）。

変更通知を受け取る 夜間現場を強調表示
A-11 数値ステッパー 新規提案

人数などの小さい整数入力用。中央はインセット入力欄（tabular-nums）、左右はフラットボタン。クリックで増減します。

A-12 検索カプセル 確立済み

SLモックの配置検索カプセルの再掲（ピル型・浅い面内グラデ）。入力可能な形にしたもの。
