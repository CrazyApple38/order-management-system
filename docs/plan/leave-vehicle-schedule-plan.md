## 1. プロジェクト全体の位置付け

- 既存の「休暇申請管理（Mockup E）」画面に **車両スケジュール管理モード** を追加
- 同一画面内のタブ切替で `休暇申請管理 ⇄ 車両スケジュール管理` を行き来
- D&D・月カレンダー・右サイドパネルといった既存UI資産を最大限再利用
- 車両スケジュールは「点検 / 修理 / オイル交換 / 車検 / タイヤ交換 / その他」の予定を月カレンダー上で管理する独立業務

## 2. 会話で確定した仕様

### 画面構成

| 論点 | 決定 |
|------|------|
| ファイル構成 | `leave-application.html` 1ファイル内で完結（モード切替） |
| 切替UI | ヘッダータイトル位置に **セグメント型タブ**（休暇申請管理 / 車両スケジュール管理） |
| 表示レイアウト | 月カレンダー型（休暇申請と同一構造）|
| 右サイドバー | 所属会社別タブ（全車 / 東央 / Nikkei / 全日本 / 期限近い）|
| ロール切替 | 車両モードでは非表示（承認フローなし）|
| 凡例 | モード切替時に「種別凡例」へ差し替え |
| 圧縮・集計ボタン | 車両モードでも保持（未実装でも見た目だけ）|

### 車両モードのカレンダー操作

| 論点 | 決定 |
|------|------|
| 配置方法 | 右パネル車両バッジ → セルにD&D（休暇申請と同一操作性）|
| 種別選択 | ドロップ後にポップアップで種別選択（点検/修理/オイル/車検/タイヤ/その他）|
| その他種別 | 「その他」選択時にテキスト入力欄が現れる、入力テキストをラベルに採用 |
| バッジ構造 | **親バッジ（車両ナンバー）** + **子バッジ（種別を多数追加可能）**|
| バッジ主表記 | 親=ナンバー下4桁、ホバーでフル表示（品川 500 あ 1234）|
| 子バッジ色 | 種別ごとに固定色 + 種別アイコン |
| イベント項目 | 予定日・時間・期間のみ（業者/費用/ステータスは含めない）|

### 車両マスタ

| 論点 | 決定 |
|------|------|
| 規模 | 3会社×5台 = 15台（デモ）|
| 項目 | ナンバープレート全体 / 車種・車名 / 所属会社 / 次回車検期限 / 次回点検期限 |
| 管理UI | 車両モード時のサイドバーに「+ 車両追加」ボタン + 各行に編集ボタン → モーダル |
| 「期限近い」閾値 | 30日以内（車検 or 点検期限が30日以内）|

## 3. 命名規約

既存の休暇申請管理は `md-la-*` プレフィックス。車両モード固有要素は **`md-vs-*`**（vs = vehicle-schedule）プレフィックスを使用。

| プレフィックス | 用途 |
|----------------|------|
| `md-la-*` | 休暇申請管理（既存・共通含む） |
| `md-vs-*` | 車両スケジュール管理 固有要素 |
| `is-mode-leave` | 休暇申請モード時のbody/containerクラス |
| `is-mode-vehicle` | 車両スケジュールモード時のbody/containerクラス |

JSの状態:
- `laState.mode = 'leave' | 'vehicle'`
- 車両関連データは `vsState`（vehicleScheduleState）にまとめる

### 車両マスタ
```js
{
  id: 'v-001',
  numberPlate: '品川 500 あ 1234',
  numberLast4: '1234',
  vehicleName: 'ハイエース',
  company: 'touo' | 'nikkei' | 'zennihon',
  nextShakenDate: '2026-08-15',     // YYYY-MM-DD
  nextInspectionDate: '2026-06-10'  // YYYY-MM-DD
}
```

### 車両予定
```js
{
  id: 'vs-001',
  vehicleId: 'v-001',
  date: '2026-05-20',
  startTime: '09:00',  // optional
  endTime: '12:00',    // optional
  kind: 'inspection' | 'repair' | 'oil' | 'shaken' | 'tire' | 'other',
  otherLabel: ''       // kind === 'other' のときのみ
}
```

### 種別定義
```js
const VS_KINDS = [
  { id: 'inspection', label: '点検',     color: '#1976d2', icon: 'wrench' },
  { id: 'repair',     label: '修理',     color: '#d32f2f', icon: 'tool' },
  { id: 'oil',        label: 'オイル',   color: '#f57c00', icon: 'drop' },
  { id: 'shaken',     label: '車検',     color: '#7b1fa2', icon: 'cert' },
```

アイコンは既存スプライト or icooon-mono から流用。`CLAUDE.md` のアイコン運用ルールに従う。
