# Q-G Test Design (TD) v1

サブフェーズ: **Q-G — QA 旧クラス・旧変数最終整理 / 完了度検証**

作成日: 2026-04-20

## 目的

- 死変数（定義されているが参照ゼロ）の洗い出しと除去（`--night-text` は QA 本文参照ゼロ）
- 本文の hard-coded HEX / rgba が妥当な範囲に収まっているかを確認
- 未定義変数参照の有無を確認
- 最終的な QA 新DS移行完了度を算出

## 配点

| 区分 | 配点 |
|------|-----:|
| A. 死変数除去 | 20 |
| B. 未定義変数検出 | 30 |
| C. hard-coded 色値検出 | 20 |
| D. JS 互換性最終確認 | 20 |
| G. 完了度サマリ | 10 |

合格: 70点以上 AND 重大Claim=0

## テスト項目

- T1 `:root` の `--night-text` を削除（QA 本文参照ゼロ、他ファイルへの波及もなし。QA 独自ファイル内のみ）
- T2 残る `:root` 変数 2 件（`--warning-text` / `--warning-bg`）が QA 本文で正しく参照されている or 通知UIで co-tokens を上書き機能する
- T3 `var(--xxx)` 参照のうち、co-tokens.css / QA :root のいずれでも未定義のものがない（32 種の全参照を確認）
- T4 本文の hard-coded HEX（`#44A6B5`, `#004554`, `#DB577B`, `#DECCBE` 等）のうち、色値として使われているものは許容範囲内（カテゴリ色分化なし・スタティックな装飾色）
- T5 JS の class 名参照（48 箇所以上）全て CSS で有効
- T6 新DS移行完了度の算出（トークン化率・alias 化率・a11y・print・touch target）

## 重大Claim

- C1 未定義 CSS 変数による描画破綻
- C2 JS が参照する class が CSS に存在しない
- C3 死変数削除で他ファイル（co-* / OB / SL / WS）に波及
