## 目的

Phase D15 の仕上げとして、WS メインセル（昼/夜）の背景を **warm beige (#F7F5F2 / #F0EDE9)** から **neutral gray (#F5F5F5 / #F2F2F1)** へ切り替え、OB と色温度を揃える。具体的には:

1. `weekly-schedule.css` `:root`（Light テーマ）の
   - `--cell-base-day: #F7F5F2;` → `--cell-base-day: var(--bg-surface-neutral);`
   - `--cell-base-night: #F0EDE9;` → `--cell-base-night: var(--bg-surface-neutral-alt);`
2. 土/日/祝 シフトヘッダの `linear-gradient(rgba(...)) , var(--bg-surface-2)` を `solid var(--day-sat / --day-sun)` に単純化。
3. Dark テーマは**スコープ外**（既存値維持）。

**D15-2 の本質的制約**: 本フェーズは意図的なビジュアル変化を伴う。ただし以下は必ず維持されること。
- 本文テキスト（`--shift-text-day: #3f3b31` / `--shift-text-night: #005c70`）の **WCAG AA 4.5:1 以上**の可読性。
- WS の既存インタラクション（セル選択・DnD・編集モーダル・日付ナビ等）が**1つも壊れない**。
- Dark テーマ（`[data-theme="dark"]` ブロック、63〜134行目付近）は**変更ゼロ**。

**スコープ外**:
- Dark テーマの `--cell-base-day` / `--cell-base-night` の改変
- OB / SL / QA の変更
- DS 側トークン追加・命名変更（D15-1 で完了済）
- WS の他の :root トークン（`--shift-bg-day` / `--shift-bg-night` / `--shift-text-*` 等）の値変更
- WS 行高・密度・カテゴリ色などのレイアウト系変更

## 評価項目（ウェイト調整後の配点）

D15-2 は「WS のビジュアル意図的変化 + 可読性・機能維持」が本質。ルーブリック標準配点（A30/B20/C15/D15/E10/F5/G5）を以下のように再配分する。

| カテゴリ | 配点 | 根拠 |
|---------|------|------|
| **A. DS準拠（トークン経由参照・WS独自値の温存なし）** | **30** | 本フェーズの核心のひとつ。`--cell-base-day/night` が `var(--bg-surface-neutral)` / `var(--bg-surface-neutral-alt)` を経由して解決されること、土/日ヘッダが `var(--day-sat/sun)` を直接参照すること、旧リテラル値（`#F7F5F2` / `#F0EDE9`）が :root から撲滅されていることを厳密に評価。標準30維持。 |
| **B. カラーコーディネーション** | **30** | WS の色温度が neutral 化し OB と整合、`--shift-text-day (#3f3b31)` / `--shift-text-night (#005c70)` が新背景上で AA 4.5:1 以上、Coastal Palette 外の色混入ゼロ。ビジュアル整合の中心軸のため 20→30 に増配。 |
| **C. タイポグラフィ・余白** | **0** | タイポ・余白系の変更なし。対象外。 |
| **D. コンポーネント一貫性** | **0** | コンポーネントクラス（`.btn-*` / `.tbl-*` / `.modal-*`）の変更なし。対象外。 |
| **E. 機能回帰（バグゼロ）** | **25** | 本フェーズは意図的ビジュアル変化を伴うので「見た目の差分ゼロ」は求めないが、**機能面は完全維持**が必須。カレンダー描画・DnD・セル選択・編集モーダル・フィルタ・ダブルクリック編集・スクロール追従 等の主要インタラクションが全て動作すること。標準10→25 へ大幅増。 |
| **F. アクセシビリティ（可読性・WCAG）** | **10** | 本フェーズは背景色が変わるため、全既存テキスト色との AA コントラストを再検算で担保する必要がある。特に `--shift-text-day (#3f3b31)` on `#F5F5F5`、`--shift-text-night (#005c70)` on `#F2F2F1` の 4.5:1 以上を数値で確認。標準5→10 に増配。 |
| **G. コード品質・保守性** | **5** | 「Phase D15-2」由来の変更であることがコメントで明記され、旧値はクリーンに除去されていること。標準5維持。 |
| **合計** | **100** |  |

**判断メモ**: C/D をゼロにした分を B（カラー整合・可読性の定量評価）と F（可読性の AA 再検算）に再配分。E を 25 に引き上げた理由は、意図的ビジュアル変化フェーズの宿命として「副作用で既存機能を壊していないか」の検証が合否を左右するため。
