## 目的

Phase D15 で扱う「画面間カラー調和」の**準備フェーズ**として、WS/OB で分散していた以下2系統のトークンをデザインシステム（DS）に昇格し、`co-tokens.css` / `styles-light.css` / `tokens.json` の**3者同時更新**により Single Source of Truth を再確立する。

1. **データグリッド用 neutral surface（Surface Tier 拡張）**
   - `--bg-surface-neutral: #F5F5F5`
   - `--bg-surface-neutral-alt: #F2F2F1`
2. **曜日別セル色（土曜・日曜の 2種 × {cell / head / cal-overlay}）= 6トークン**
   - `--day-sat: #EAF0F1` / `--day-sun: #F3ECEE`
   - `--day-sat-head: #BECAC5` / `--day-sun-head: #D4BEBD`
   - `--day-sat-cal: rgba(68,166,181,0.06)` / `--day-sun-cal: rgba(220,120,120,0.06)`

**D15-1 の本質的制約**: 値は**既存OBと同値**であるため、**OB の見た目に1pxの変化も発生してはならない**（本サブフェーズは「参照元がOB固有 :root から DS に移動するだけ」）。`order-book.css` の `--base-grid` / `--base-grid-alt` はコードベース内の既存参照数が多いため、削除せずに**DS参照エイリアス**（`--base-grid: var(--bg-surface-neutral)` / `--base-grid-alt: var(--bg-surface-neutral-alt)`）として残す。`--day-*` は同名で DS から継承可能なため :root 側からの定義を**単純削除**でよい。

**スコープ外**:
- WS メインセルの neutral 切替（→ D15-2）
- Dark テーマ（Light のみ）
- `--base-grid-total: #F0F4F4` の DS 昇格（OB 独自色、本サブフェーズでは残留）
- `order-book.css` の `--error-bg` / `--night-text` / `--success-bg` / `--semantic-warning-text` 等のOB固有残留トークン
