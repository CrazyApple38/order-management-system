# W-G Test Design (TD) v1

サブフェーズ: **W-G — WS 旧クラス・旧変数最終整理**

作成日: 2026-04-20

## 目的

- 死変数（定義されているが参照なし）の洗い出し
- 旧色値の hard-coded 参照が残存していないか確認
- 未定義変数参照の検出
- 最終的な WS 新DS移行完了度を算出

## 配点

| 区分 | 配点 |
|------|-----:|
| A. 死変数除去 | 20 |
| B. 未定義変数検出 | 30 |
| C. hard-coded 色値検出 | 20 |
| D. JS 互換性最終確認 | 20 |
| G. 完了度サマリ | 10 |

合格: 70点以上

## テスト項目

- T1 Light `:root` の全 29 変数が本文で参照されている
- T2 Dark `:root` のオーバーライド変数が全て Light に対応定義（co-tokens alias or WS固有）を持つ
- T3 `var(--xxx)` 参照のうち、co-tokens.css / WS :root / Dark のいずれでも未定義のものがない
- T4 本文の hard-coded HEX（`#44A6B5`, `#004554` 等）のうち、色値として使われているものは許容範囲内
- T5 JS の class 名参照（48箇所）全て CSS で有効
- T6 新DS移行完了度の算出（トークン化率・alias 化率・a11y・print・Dark 対応）

## 重大Claim

- C1 未定義 CSS 変数による描画破綻
- C2 JS が参照する class が CSS に存在しない
