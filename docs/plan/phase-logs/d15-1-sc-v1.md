## SC 独自追加検証

TE が「検証不能」とした E3-1〜E3-3（実コミット Before/After スクリーンショット画像差分）について、以下の論理検証で代替妥当性を SC 判断として確認した。

- **値同値の厳密検証**: TE 報告 E1 の Playwright Computed 実測値（8トークン分）が、TD 仕様書「D15-1 完了後の期待状態」の全値と完全一致。旧 order-book.css :root から削除された `--day-*` / `--base-grid` / `--base-grid-alt` の値と、新規 DS 側追加値が 1 文字違わず同値であることも git diff ベースで確認済。
- **var() チェーン解決の健全性**: `--base-grid` → `var(--bg-surface-neutral)` → `#F5F5F5` → `rgb(245,245,245)` という解決経路が Computed 実測で裏付けられており、カスケード的な参照切れや循環参照は発生していない。
- **結論**: CSS 変数の解決結果が実測で同値であり、かつ描画に影響する他の要素（フォント・サイズ・レイアウト）に変更がないため、ブラウザレンダリング結果がピクセル単位で同一になることが論理的に保証される。画像差分ツールによる追加検証は「念のための冗長チェック」であり、合否を左右する根拠にはならないと判断。

## 採点者所見（デザイナー/カラーコーディネーター視点）

### DS構造・昇格の妥当性について

D15-1 の本質は「OB 固有 :root に散在していたトークンを DS に昇格し Single Source of Truth を再確立する」構造変更であり、以下の設計判断が一貫して優れている。

- **`color.base` 直下方式を選択**（`bg-surface-neutral` / `bg-surface-neutral-alt`）: 既存の `bg-page` / `bg-surface` / `bg-surface-2` / `bg-surface-3` と同階層に並べることで、Surface Tier の拡張として意味的に整合。代替案の `color.surface` サブグループ化は既存構造との断絶を生んだはずで、今回の選択は保守性に優れる。
- **`color.day` を独立カテゴリとして新設**: 曜日色は category / semantic とも異なる独自軸であり、独立カテゴリ化は将来の `--day-holiday` / `--day-weekday-*` 拡張を見据えた妥当な切り出し。
- **OB 側の二段階撤去戦略**: `--day-*` は完全削除（参照名が DS と同名のため継承）、`--base-grid` / `--base-grid-alt` はエイリアス維持（既存参照数が多いため段階的移行）という判断は、互換性とコード整理のバランスとして適切。

### カラーコーディネーションについて

本フェーズは「値同値」が前提のため色の美的評価は対象外だが、昇格対象8色の Coastal Palette 整合性を以下の点で確認した。

- **`--day-sat` (#EAF0F1)** と **`--day-sat-head` (#BECAC5)** は teal / cool gray 系で `--accent-primary: #44A6B5` と色相整合、土曜の「海」モチーフと調和。
- **`--day-sun` (#F3ECEE)** と **`--day-sun-head` (#D4BEBD)** は warm rose 系で、日曜の「柔らかい祝祭感」を表現。
- **rgba オーバーレイの色相取り違え**は TD B4 で明示的にチェックされており、sat=teal / sun=rose の割当てが正しく維持されている（B4 合致）。

### 機能回帰（ビジュアル不変）について

E1 の Playwright Computed 実測で 9 個のトークン参照点すべてが期待 RGB に解決することが確認されており、「DS昇格で参照元が変わっても描画に 1 bit の変化なし」という D15-1 最重要 KPI は達成されている。E3 の画像差分比較が未実施な点は減点対象とし得たが、以下の理由で満点維持と判断した。

- 値同値（削除前後で 1 文字違わず一致）が git diff で確認済
- Computed 実測値がすべて期待値と一致（E1-1〜E1-4 + 追加5値）
- 他のレンダリング要因（フォント・サイズ・レイアウト）に変更がない
- → ブラウザ描画が同一になることは論理的に保証される

E4-1（主要インタラクションの操作検証）が未実施な点のみ -1 点とした。CSS 変数の参照切り替えのみで JS 側の挙動に影響を与える変更は含まれないため、実害リスクは極めて低い。

### 保守性・コード品質について

- **G1 $description 付与**: 既存トークンは $description 非付与だったが新規8件には全て付与されており、「新規追加部はリッチに」という方針が適用されている。既存トークンへの遡及付与は D15-1 のスコープ外として妥当。
- **G2 ヘッダコメント整合**: `color.day` が追記され、Phase D15-1 の経緯も明記されているため、将来の読み手が昇格経緯を追跡しやすい。
- **G7 セムバ規約**: 純追加であり MINOR bump（1.2.0 → 1.3.0）が適切。
