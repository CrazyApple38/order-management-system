## 目的

D15-2 の副作用として発生した `--text-tertiary: #5A8896` の AA 未達（#F5F5F5 上 3.57:1、#F2F2F1 上 3.47:1、#FFFFFF 上 3.92:1）を解消する。具体的には:

1. **値差し替え（3者同期）**: Light テーマの `--text-tertiary` を `#5A8896` → `#476E7B` に更新
   - co-tokens.css（45行目付近）
   - styles-light.css（25行目付近）
   - tokens.json `color.text.tertiary.value`（29行目付近）
2. **コメント更新**: co-tokens.css / styles-light.css の `--text-tertiary` 行末コメントを Phase D15-3 記述に更新
   （例: `/* Phase D15-3: #5A8896 → #476E7B で全neutral背景でAA達成 (5.09:1 on #F5F5F5) */`）
3. **tokens.json メタ更新**:
   - `$version` `1.3.0` → `1.3.1`（PATCH バンプ、既存値変更）
   - `color.text.tertiary.$description` を D15-3 文言に更新

**D15-3 の本質的制約**:
- 変更は Light テーマの `--text-tertiary` **1トークンのみ**。3者（co-tokens.css / styles-light.css / tokens.json）で値が完全一致すること。
- `#476E7B` は Coastal Palette の teal/blue-gray 系で、既存 `--text-secondary: #2A6B7A` / `--accent-primary: #44A6B5` と色相整合が取れていること。
- 全主要 surface 背景（`#FFFFFF` / `#F5F5F5` / `#F2F2F1` / `#F0EDE9` / `#E9F1F6`）上で AA 4.5:1 以上を達成すること。

**スコープ外**:
- Dark テーマの `--text-tertiary: #8a8480`（別フェーズ）
- `--text-disabled: #8BAEB9`（AA 対象外の補助色）
- 他トークン（`--text-primary` / `--text-secondary` 等）の変更
- 他ファイル（`weekly-schedule.css` / `order-book.css` / `screen-layout.css` / `quick-access.css` / `styles.css` (Dark) 等）の編集
  （`var(--text-tertiary)` 参照箇所は自動で新値に追従するため、CSS 編集は不要）
