# Q-C Test Design (TD) v1

サブフェーズ: **Q-C — QA テーブル整合（スキップ）**

作成日: 2026-04-20

## 目的

QA はモバイル寄りUIであり、画面構造が「ログイン → 契約先カード一覧 → カレンダー → 編集パネル」の4段階遷移。**テーブル構造（`<table>` / `.md-tbl-*`）を一切使用しない**（契約先はカード、日付はカレンダーセル、編集は縦並びフォーム）。

そのため本サブフェーズはスキップ対象。評価対象テストなし、満点扱いとする。

## 配点

| 区分 | 配点 |
|------|-----:|
| — | 100（N/A 満点扱い） |

合格: 自動 PASS

## テスト項目

- T1 QA HTML 内に `<table>` 要素が存在しない（確認のみ）
- T2 QA CSS に `.md-tbl-*` セレクタが存在しない
