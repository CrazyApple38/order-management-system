② 和文フォント指定 — OS間の統一

現状は -apple-system, Segoe UI, Roboto のみで和文フォント無指定。 Windows では游ゴシック or Meiryo、Mac ではヒラギノにフォールバックされ OS間で別プロダクト化。 Noto Sans JP / Hiragino Sans を明示すれば統一できます。 font-feature-settings: "palt" で和文の間延びも解消。

⑪ 2テーマ整合 — ライト/ダークのブランド統一

現状はライト accent (#44A6B5) とダーク accent (#098698) で 明度カーブが別物。HSL空間で色相・彩度を揃え、明度のみ反転することで 「テーマ切り替えで別サービスに見える」現象を解消します。

旧（2テーマ別物）
ライト: #44A6B5
hsl(187, 46%, 50%)
ダーク: #098698
hsl(186, 88%, 32%)

彩度・明度が別物。切り替えるとブランドが変わった印象

新（HSL統一）
ライト: #44A6B5
hsl(187, 46%, 50%)
ダーク: #55B5C4
hsl(187, 46%, 55%)

色相・彩度完全一致、明度のみ5%差。ブランド一貫性が保たれる
