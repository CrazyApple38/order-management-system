Modal Design Pattern（確定仕様）

modal-* プレフィックスに統一（ob-modal-* は廃止）。画面固有でない共通パターンとしてシンプルな命名を採用。

コンテナ.modalモーダル本体
ヘッダー.modal-headerタイトル＋閉じるボタン
ボディ.modal-bodyスクロール可能な内容領域
フッター.modal-footerアクションボタン領域
閉じるボタン.modal-close✕ボタン（ヘッダー右上）
セクション区切り.modal-section-barテキスト＋横線の区切り
カード.modal-body-card白背景のグループ化カード
フィールド見出し.modal-body-fieldUsage Map風フィールド見出し
配置先タブ.ob-placement-tabsマルチサイト配置先のタブ切り替え
業務名表示.ob-cal-display-value読み取り専用の業務名表示（下線付き）

バリアントクラス幅用途例
