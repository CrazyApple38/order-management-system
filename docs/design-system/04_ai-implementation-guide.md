# 04. AI 実装ガイド（エージェント非依存プロトコル）

**最終更新**: 2026-07-11（R-3f #5 承認済み角丸例外と WARN=0 基準を追記）
**対象**: 本プロジェクトで実装を行うすべての AI エージェント（Claude Code / Codex / Gemini ほか）と人間。
**目的**: 実装者が変わってもデザインが 1px 単位でブレないための手順・規則・自己検査。

## 2. 絶対規則（10ヶ条）

1. **値を発明しない** — 色・影・角丸・グラデ・フォントサイズは必ず `ds-tokens.css` のトークン参照か
   `ds-components.css` の既存クラスで実現する。新しい hex / px / rgba を書いた時点で違反
2. **クラス優先** — 新しい CSS を書く前に `ds-components.css` を検索。無ければ 02 §1 の語彙ファミリーの
   レシピを組み合わせる。それでも必要なら**実装せずユーザーへ提案**
3. **光源第一条を守る** — グラデ=左上明→右下暗 / border=上左明・右下暗 / 影=下方向。
   例外は 01 §1.1 の 3 つだけ（カプセルバッジ中央凹み / 要対応グロー / インセット反転）
4. **意味色を転用しない** — 夜間赤=夜間文字だけ、Signal Orange=警告だけ、緑=在席ドットだけ。
   正常状態を緑で主張しない。区分に色相を増やさない
5. **濃色面の使用権**（ナビ / 未確認シグナル / 選択状態 + ツールチップ）以外に濃紺ベタを使わない
6. **アイコンは `docs/assets/icons/` の SVG のみ** — 絵文字・Unicode 記号・外部 CDN アイコン禁止。
   方向記号は `.chev`（CSS 描画）
7. **icon-only ボタンには `title` + `aria-label` 必須**。装飾要素は `aria-hidden="true"`
8. **禁止判例（01 §5）を再提案しない** — 所属色フレア・角丸四角人物バッジ・3連インフォタイル・
   全面ニューモーフィズム等は「過去に試作して却下済み」。同型の再提案は工数の無駄
9. **迷ったら実装せず質問** — 特に視覚デザイン（色・形・サイズ・配置）は指示されていない属性を触らない。
   「ついでに良くする」は禁止。確認は選択肢提示形式で
10. **正本を書き換えない** — `docs/preview/design-refresh-*.html` は参照専用。
    `ds-*.css` / 本文書群の変更はユーザー承認 + README §3 の同期手順に従う

## 3. 実装の型（コピー元の指定）

- **コンポーネントを置く** → 02 の表で ID を特定 → カタログ HTML の該当 `<article data-comp="X-nn">` から
  DOM をコピー → クラスはそのまま使う（改名しない）
- **レイアウトを組む** → SL 層モックの該当部位（02 §6 の表）から DOM をコピー
- **画面固有スタイルが必要** → 「ds-tokens のトークンのみを参照する画面 CSS」として画面ファイル側に書く。
  ds-components.css には画面固有スタイルを足さない
- **co-tokens.css を撤去する画面** → `ds-tokens.css` の直後に **`ds-legacy-aliases.css`（正準エイリアス）** を読み込む。
  旧トークン名のエイリアスを画面 CSS に自前で再導出・重複定義しない（03 §3.3。
  画面固有の density / chart-seq 等のみ *-ds.css 側）。SL のみ例外で `ds-tokens-bridge.css` を継続（R-3f まで）
- **JS の挙動** → 見た目に関わる状態クラス（`.active` / `.is-selected` / `.open` / `.cn-flash` 等）の
  付け外しだけで表現し、インライン style での色・影の直接操作をしない

## 4. 実装後セルフレビュー・チェックリスト

コミット前に全項目を確認する（1つでも NG なら修正）:

- [ ] 新規の hex / rgba / px 影 / px 角丸を書いていない（トークン・既存クラスのみ）
- [ ] `linear-gradient(to bottom right, …)` がすべて明→暗（例外①③以外）
- [ ] border の明暗: 上・左=白系 / 右・下=青灰系（浮き面の場合）
- [ ] box-shadow の暗影がすべて下方向（Y ≥ 0。白カウンター影のみ上方向可）
- [ ] インセット面（入力欄・seg・彫り込みフレーム）だけが左上暗→右下明
- [ ] 数値・時刻に `tabular-nums`、中央揃えは規範どおり
- [ ] テーブルに縦罫線を追加していない
- [ ] 塗りの主操作ボタンが 1 画面 1〜2 個以内
- [ ] 危険操作が薄背景+オレンジ文字（強い塗りにしていない）
- [ ] 緑・ピンク・ティール等の廃止色が新規に出現していない
- [ ] icon-only ボタンに title / aria-label がある
- [ ] 絵文字・Unicode 記号アイコンを使っていない
- [ ] 旧 `co-tokens.css` と新 `ds-tokens.css` を同一ページで併載していない
- [ ] `node scripts/design-audit/ds-audit.js` が **NG=0 / WARN=0**（未定義 var() 参照・併載・直書き値の機械検査）
- [ ] script 読込順・cnJump・スポットライト着地など SHARED-MEMORY の禁止事項に触れていない

## 5. 検証手順（Playwright）

1. **静的監査**: `node scripts/design-audit/ds-audit.js` → **NG=0 / WARN=0** を確認。
   CSS カスタムプロパティの未定義参照は**コンソールエラーを出さずに黙って無効化**する
   （経緯: R-3d で太字・意味色が無効化したままコンソール 0 で完了扱いになり、
   2026-07-10 の横断レビューで OB/WS にも同型欠落が発覚）。コンソール確認だけでは検出できない
2. `http://localhost/order-management-system/...` で対象画面を開く（XAMPP。file:// は fetch 系が動かない点に注意）。
   **HTML 自体はキャッシュバスターが付かないため、再検証時は `?cachebust=N` 等を URL に付けて旧 HTML の再利用を防ぐ**
3. コンソールメッセージ 0（エラー・警告とも）を確認
4. **computed style 実測**: 変更したトークン・スタイルの効き先を `getComputedStyle` で実測する
   （例: font-weight が 600 か、padding が 0 に潰れていないか、意味色が透明化していないか）。
   目視スクリーンショットは「崩れて見えない崩れ」（ウェイト・数 px の余白）を拾えない
5. 1440px 幅基準でフルページスクリーンショットを **`screenshots/`** ディレクトリへ保存
   （プロジェクトルート直下に PNG を散らかさない — 保存先規約）
6. 基盤 CSS 自体を変更した場合は `docs/preview/ds-foundation-test.html` も再確認
   （合格基準: `screenshots/ds-foundation-test.png` と同等の描画・コンソール 0）
7. 変更した HTML の `<link>`/`<script>` キャッシュバスター `?v=N` を更新したか確認
