# 01. デザイン原則とトークン — Calm Operations

**最終更新**: 2026-07-03
**トークン値の正本**: `docs/mockup/ds-tokens.css`（本書は用途と規範のみ。値はコピーで使う）

## 1. DS 第一条: 光源は左上固定

すべての立体表現は「画面の左上に光源がある」前提で統一する。**これが本 DS の最重要規則**。

| 表現 | 規則 | 実装形 |
| --- | --- | --- |
| 面グラデーション | 左上=明 → 右下=やや暗 | `linear-gradient(to bottom right, 明色, 暗色)` |
| ベベル（縁の立体） | 上・左 border = 白（受光）/ 右・下 border = 暗（陰） | `border: 1px solid rgba(255,255,255,.88); border-right-color/border-bottom-color: 青灰系` |
| ドロップシャドウ | 下方向のみ（`0 Npx …`）。横・上方向の暗影は禁止 | `--elevation-1`〜`--elevation-5` |
| 押し込み面（インセット） | **唯一の反転**: 左上が壁の影で暗く、右下が明るい | 入力欄・seg トラック・彫り込みフレーム |

**実装後の自己検査**: グラデの `to bottom right` で明→暗になっているか / border の明暗が上左=明・右下=暗か / `box-shadow` の Y オフセットが正か。

### 1.1 公式例外（これ以外の例外を作らない）

| 例外 | 対象 | 内容 |
| --- | --- | --- |
| ① カプセルバッジの中央凹みグラデ | `.person` / `.vehicle-tag` / `.user-chip` | 青灰→白(60%)→青灰 の「中央が凹んで見える」グラデ。本デザイン最大の特徴部位のため光源統一の対象外（ユーザー確定 2026-06-11） |
| ② 要対応バッジの極小グロー | `.bell-count` 等の**要対応・警告系バッジ限定** | 橙ハロー `0 0 12px 3px rgba(241,94,42,0.75)`。「意味のある光」の公式例外。装飾用の光・所属色フレアは引き続き不採用 |
| ③ 白カウンター影 | `--shadow-card-outer` の第1層 | 上方向の淡い白光 `0 -2px 6px rgba(255,255,255,0.55)`。ニューモーフィズムの部分採用（カード浮きの対の光） |

## 2. 濃色面の使用権（3つ + ツールチップ）

濃紺・濃色のベタ面は以下だけに使える。**新しい使用先を追加しない**。

1. **ナビゲーション面** — メニューバー（`--blue-dark`）、左レール（`.rail` の濃紺グラデ内面）
2. **未確認シグナル** — 権利として保持（現行モックでは変更履歴カード淡色化により未使用。2026-06-11 判断）
3. **選択状態（濃紺選択ピル）** — `.filter-btn.active` / `.pg-btn.current`。濃紺ベタ＋白文字
4. ツールチップ（濃紺ポップ `rgba(20,38,53,0.94)`）は情報オーバーレイとして許可

## 3. 意味色の体系（転用禁止）

色は「意味」に対して割り当てる。**別の意味に流用しない**。

| 意味 | 色 | 表示形 | 強さの序列 |
| --- | --- | --- | --- |
| 夜間現場（慣習表示） | Flexoki Red `--night-text: #d14d41` | **文字色のみ**（契約先/現場名・時間・人数・配置社員名）。バッジ化しない | 慣習として固定。警告とは別意味 |
| 配置警告（資格不足・NG関係・連勤超過・人数不足） | Signal Orange `--alert-text: #f15e2a` / `--alert-bg` / `--alert-border` | アイコン集約＋ホバーで理由表示。人数不足のみ `不足` バッジ | 唯一目立つ高彩度色 |
| 情報差分（地図未設定・OB更新あり 等） | 青灰 `--info-text` / `--info-bg` / `--info-border` | 枠付き情報バッジ | 警告より弱く通常情報より強い |
| 主操作・現在位置・区分 | ブルー `--blue: #1f5fae` | 塗りボタン・アクティブタブ・区分バッジ | — |
| 正常状態 | ニュートラル `--neutral-chip-*` | **緑で主張しない**。非表示 or ニュートラル | 最弱 |
| GC（グループ会社） | 行の薄い背景 + ホバーポップアップ | 常時の文字表示は避ける | 区分より弱い |
| 所属会社（belong） | `--belong-1`〜`--belong-10` | 人物シルエット `.person-icon` の fill / 車両タグ左情報。全面塗りしない | GC 行背景より強く警告・夜間より弱い |
| 在席 | 緑ドット `.presence-dot`（#39c26d） | ユーザーチップ内のみ | — |

**色数の比率目安**: 70% ニュートラル（白・薄青灰・濃スレート）/ 20% ブルー（主操作・選択・区分）/ 5% 夜間赤文字 / 5% 警告オレンジ。

## 4. トークン一覧（用途注記。値は ds-tokens.css を正とする）

### 4.1 基本色

| トークン | 用途 |
| --- | --- |
| `--bg` | キャンバス基調（#eef4f8 薄青灰）。body は radial+linear の浅いグラデ |
| `--panel` | カード・パネルの白 |
| `--ink` / `--muted` | 本文 / 補助文字 |
| `--line` / `--soft-line` | 罫線 / さらに弱い罫線 |
| `--blue` / `--blue-dark` / `--blue-soft` | 主操作・区分 / メニューバー / 淡青面 |
| `--accent-orange` 系・`--alert-*` | 警告（§3 参照） |
| `--night-text` | 夜間文字（§3 参照） |
| `--info-*` / `--neutral-chip-*` | 情報差分 / ニュートラル状態 |
| `--rail-dark-*` | 暗色レール上の境界・押し込み面・補助文字（R-3f #5） |
| `--confidence-tentative-high/low` | 受注確度の暫定高/低。警告色とは分離 |
| `--gc-*` | GC 行背景・GC 色（belong に連動） |
| `--belong-1..10`（+ `-bg` / `-border`） | 所属会社 10 社分。1〜5 は淡いパステル8色パレットの初期割当（A=Slate Blue #AFC5E6 / B=Fresh Green #B4DDC5 / C=Bright Mauve #CDBFEA / D=Soft Yellow #EEDDA2 / E=Coral Rose #EDBCBC）。実運用では設定 UI から `color-mix` で -bg(10%)/-border(32%) を導出 |

### 4.2 立体・形状

| トークン | 用途（高さレイヤーの意味論） |
| --- | --- |
| `--elevation-0` | ツールバー・フラット面（高さ 0） |
| `--elevation-1` | 通常ボタン・section・ライトカード hover |
| `--elevation-2`〜`-3` | 外側パネル・アクティブタブ・カード |
| `--elevation-4` | ドロップダウンメニュー |
| `--elevation-5` | 最上位: 左レール・モーダル・トースト・レール通知カード |
| `--shadow-card-outer` | 浮きカードの4層影（白カウンター影+リング+2層暗影）。`--bevel-card` とセットで使う |
| `--bevel-card` | 左上明・右下暗の 1px インセットベベル |
| `--inset-highlight` / `--inset-edge` | 面上端の白ハイライト / 下端の陰 |
| `--radius-xs/sm/md/lg/pill` | 4/8/14/20/999px。xs=チップ内要素 / sm=ボタン・小カード / md=大カード / lg=トレイ / pill=カプセル。**このスケール外の角丸を作らない** |

承認済み局所例外（R-3f #5）: LA seg 内側の6px同心角丸と、WS極小チップの3px角丸。監査はファイル単位で限定許可し、新規利用へ拡張しない。

**D&D 対象（カプセルバッジ）は通常カードよりわずかに高い影**（2層影 `0 4px 8px` + `0 2px 3px`、hover で増強）。

### 4.2.1 モーション・z 層・モーダル幅（2026-07-03 旧 DS から正式移設・値は不変）

| トークン | 用途 |
| --- | --- |
| `--duration-instant/fast/base/slow/slower` | 0/120/200/320/480ms。UI transition の基準は 120〜160ms（`--duration-fast` 帯。02 §7） |
| `--ease-out/in/in-out/spring` | イージング。通常は `ease` か `--ease-out` |
| `--z-dropdown/sticky/overlay/modal/popover/tooltip/toast` | 重なり順 100/200/900/1000/1100/1200/2000 |
| `--modal-w-sm/md/lg/xl` | モーダル幅 380/480/600/800px |

### 4.3 タイポグラフィ

- フォント: `--font-sans`＝Inter + Noto Sans JP（Google Fonts、weight **400〜700 のみ**読込）
- 画面タイトル 18〜20px/700、セクション見出し 13〜14px/700、表本文 12〜13px（`--table-font`）、
  主要数値・時刻 14〜18px/600（`--table-num`、**必ず `font-variant-numeric: tabular-nums`**）、補助 11px を下限とし多用しない
- 重要数値は色でなく**太さ・配置・余白**で強調する

### 4.4 罫線・影の運用

- 縦方向の列罫線は**原則使わない**（列間の余白と整列で区切る）。横罫線は `--soft-line` 基調
- 行グループ区切りだけ少し強く、セル単位の境界は弱く
- ドロップゾーンの点線は常時表示せず、ドラッグ中/ホバー時のみ強調
- 影は「操作可能・面の重なり」を示す手段。色数を増やす代替として使う
